  meow is an open-source interpreted systems programming language wihout a parser or lexer. It's designed to solve any task: console, web, desktop and much more! meow combines dynamic module system management and a file-based execution system. It's built to be fast, lightweight, and super easy to learn for everyone! Enjoy! (:

# Why meow
- **Fast**: Dynamic module system management makes meow super fast!
- **Lightweight**: The meow interpreter is smaller than 1 MB.
- **Easy to learn**: Simple meow documentation is ready for you to read!
- **Think different**: Dynamic module system management and a file-based execution system

# How meow thinks
| System | Explanation |
| --- | --- |
| Dynamic module system management | While the program is running, in code you can deimport some modules that make the program run faster, because the interpreter doesn't need unnecessary checks. |
| File-based execution system | Instead of functions, you run other `.meow` files — this keeps your code much cleaner. |

# How to install
1. Download the latest version
2. Open install.bat (for Windows) or install.sh (for Linux/macOS)
3. Restart your terminal and run `meow version` to make sure the installation is completed successfully
4. **Enjoy!**
